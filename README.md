## EDU-CONSULT — Conseil & développement informatique

Je suis Fabien Toune, fondateur d'**EDU-CONSULT**, basé à Sambreville (Belgique). Depuis 2003, j'accompagne entreprises, établissements d'enseignement et organisations dans leurs projets informatiques, sur site ou à distance. Master en sciences informatiques (UNamur).

### Services

- **Développement web & applications** — applications métier sur mesure, API REST, logique métier complexe (Python, Django, PostgreSQL)
- **Outils d'administration & intranets** — digitalisation des processus internes, tableaux de bord, reporting, automatisation
- **Infrastructure & sysadmin** — serveurs Linux, virtualisation Proxmox, conteneurs Docker, réseaux, pour TPE et établissements
- **Formation** — programmation Python, algorithmique, analyse et modélisation (UML), pour équipes techniques ou adultes en reconversion

### Approche

Comprendre les contraintes métier avant de proposer une solution technique. Pas de framework inutile, pas d'over-engineering : du code propre, documenté et évolutif.

### Outils

Python · Django · PostgreSQL · JavaScript · HTML/CSS · Linux (Debian) · Docker · Proxmox · Git
