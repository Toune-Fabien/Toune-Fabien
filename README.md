## EDU-CONSULT — Conseil & développement informatique

J'accompagne depuis 2003 entreprises, établissements d'enseignement et organisations dans leurs projets informatiques : de l'analyse du besoin à l'application en production, jusqu'au serveur qui l'héberge. Sur site ou à distance, partout en Belgique.

### Services

- **Applications web et mobiles** — applications métier sur mesure, API, logique métier complexe
- **Outils d'administration & intranets** — digitalisation des processus internes, tableaux de bord, reporting, automatisation
- **Infrastructure & sysadmin** — serveurs, virtualisation, conteneurs et réseaux, pour TPE et établissements
- **Formation** — programmation Python, algorithmique, analyse et modélisation (UML), pour équipes techniques ou adultes en reconversion

### Approche

Comprendre les contraintes métier avant de proposer une solution technique. Pas de framework inutile, pas d'over-engineering : du code propre, documenté et évolutif.

### Technologies

- **Back-end** : Python · Django · PostgreSQL · API REST
- **Front-end & mobile** : Vue.js · JavaScript · Android
- **Infrastructure** : Linux · Docker · Proxmox
